# Brand assets

This directory contains the project identity assets used in documentation and social publishing.

| File | Use |
|---|---|
| `telegram-archive-logo.png` | Repository, bot, and release identity |
| `telegram-archive-api-icon.png` | Secure API + AI callouts |
| `telegram-archive-instagram-post.png` | Instagram announcement artwork |

The visual direction uses deep navy, cyan, amber, and white. Keep clear space around the logo and do not stretch or recolor the icons without preserving contrast.
